# Job Board Website

## 📌 Project Description

A full-stack Job Board application that enables employers to post job openings and job seekers to search and apply for jobs.

## 🚀 Features

* User Registration and Login
* Employer Dashboard
* Post, Edit, and Delete Jobs
* Browse and Search Job Listings
* Apply for Jobs
* Responsive User Interface
* Protected Routes with Authentication

## 🛠️ Technologies Used

* React.js
* Node.js
* Express.js
* MongoDB
* HTML5
* CSS3
* JavaScript
* Bootstrap / Tailwind CSS

## 📂 Project Structure

* Frontend
* Backend
* Database
* Authentication
* API Integration

## ⚙️ Installation

1. Clone the repository.
2. Open the project in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```
4. Start the development server:

   ```bash
   npm run dev
   ```
5. Open the application in your browser.

## 📸 Main Modules

* Home Page
* Login & Registration
* Employer Dashboard
* Job Listings
* Job Details
* Apply Job
* User Profile

## 🎯 Objective

To provide a simple and efficient platform where employers can publish job opportunities and candidates can easily search and apply for suitable jobs.
